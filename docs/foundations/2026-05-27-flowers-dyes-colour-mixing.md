# Flowers, Dyes & Colour Mixing

**Date:** 2026-05-27
**Status:** PHASE 1 DELIVERED 2026-05-27 (coordinated with Spec 36). The three
flowers (Cornflower/Field Poppy/Buttercup, blocks 131-133) generate wild on
grassland via `place_vegetation`, break to themselves, and each presses to its
primary dye (BlueDye/RedDye/YellowDye). Textures 220-222 (flowers) + 225-227
(dyes). **Delivered since (follow-ons, 2026-05-28):** **dyed paper + décor**
(wallpaper + bunting/paper lanterns/kites/banners/sails/tents); the
**flower-mixing + dye-mixing paths** + **Black/White** and the full 16-colour
paintbox (Phase 2); and **farmable** flowers (plantable on tilled soil). Note:
the **blue blueprint is NOT a dye consumer** — it's a
sun-printed cyanotype (separate spec, `2026-05-27-blueprint-cyanotype.md`).
PWA/WASM + native.

**Playtest bugfix 2026-05-28 — flowers were too big and couldn't be picked.**
Two latent bugs surfaced the moment Axolittle tried to harvest a wild flower:

1. **Sizing.** `mesh::non_solid_shape_for` had no bespoke entry for the
   flowers — they fell through to the catch-all default `(0.12..0.88, 0..1.0,
   0.12..0.88)`, a 0.76 × 1.0 × 0.76 cube that's *wider and taller* than
   tall grass. Fix: bespoke flower AABB `(0.30..0.70, 0..0.65, 0.30..0.70)`
   so all three flowers read as compact stems rather than chunky cubes.
2. **Targeting.** `raycast::cast_ray` filtered hits by `is_solid(block)` —
   so the player's cursor passed straight through every non-solid plant
   (flowers, every crop stage, tall grass, fibre plants, torches…) and the
   break/drop pipeline never even fired. This bug had been latent since
   the very first block-break commit (`16880b2`); the flowers exposed it
   because they're the first plant the player actively tries to collect.
   Fix: new `raycast::is_pickable` helper — solid blocks always qualify,
   non-solid blocks qualify too *except* AIR / WATER / CAMPFIRE_SMOKE
   (water keeps its see-through behaviour; smoke is regenerated by the
   campfire tick so breaking it would be a wasted swing).

Regression tests pin both behaviours: `raycast::tests::ray_hits_flower_block`,
`raycast::tests::ray_passes_through_water`, `mesh::tests::wild_flowers_have_compact_shape`.
**Driver:** Axolittle. **Captured by:** Staxolottle's call to "do all the
colours we'll need" but via *primary colours you mix*, not a flower per
colour. Text-only design (no visual companion) per owner, 2026-05-27.

## Origin

This fell out of the Build Schematics work. We wanted the captured **Plan**
("blueprint") to read blue like a real blueprint, but recolouring ancient
papyrus blue is an anachronism. Axolittle's instinct fixed it: **you should
get a flower, craft it into dye, then use the dye** — and rather than a
separate flower for every colour, grow a few **primary** flowers and **mix**
them. That earns the blue in-world (you dyed the paper) and opens a whole
colour economy: coloured plans now, wool/banners/etc. later.

This is also the game's **first flower** — there are no flowers yet (only
tall grass, berry bushes, papyrus reeds, saplings, crops).

## Model

Three layers, each a clean step:

```
flower (world / farm)  →  dye (craft)  →  use (dye paper, later wool/banners)
                                   ↑
                          mix two dyes → new colour
```

### 1. The flowers (sources)

Three **primary-dye wildflowers**, all real UK wildflowers (UK English,
no trade-dress risk, genuinely educational on primary colours):

| Flower | Dye | Notes |
|---|---|---|
| **Cornflower** | Blue | The one that started this; cornflower-blue is real. |
| **Field Poppy** | Red | Common UK red wildflower. |
| **Buttercup** | Yellow | Common UK yellow wildflower. |

- Each is a **single-block decorative plant**, scattered in grassy biomes by
  the same worldgen vegetation pass that now places tall grass + berry bushes
  (`World::place_vegetation`, added 2026-05-27). Rarer than grass, clustered.
- Harvest (break) → drops **1 flower item** of that type.
- **Farmable** (delivered 2026-05-28): plantable on tilled soil like crops —
  grows through 3 stages, drops the flower + seeds. Wild scatter remains the
  bootstrap source.

### 2. Dyes (craft)

Shapeless grid recipe, **1 flower → 1 dye**:

- Cornflower → **Blue Dye**
- Field Poppy → **Red Dye**
- Buttercup → **Yellow Dye**

Two non-flower primaries for shading, sourced from mobs we already have:

- **Black Dye** ← **Ink Sac** (dropped by **Squid** — now visible as of
  2026-05-27). Nice tie-in: the squid finally earns its keep.
- **White Dye** ← **Bone Meal** (Bone → Bone Meal), or an **Oxeye Daisy**
  white flower if we'd rather keep white in the flower family. *Decision
  deferred to build: prefer Bone Meal (no 4th flower needed).*

### 3. Mixing (the paintbox) — text table

Subtractive **RYB** mixing (what kids learn in art class). Combine two dyes
in the grid → **2 of the mixed dye** (quantity-conserving, like the genre
standard). Tints/shades add White/Black.

**Two paths to a secondary (owner call, 2026-05-27).** You can reach each
secondary *either* by mixing two **dyes** *or* by mixing the two **flowers**
directly — same result, both yield 2 dye. The flower path is a shortcut
straight to a secondary when you've got the petals but haven't pressed them
into single dyes yet. (You still make *single* primary dyes the one-flower
way, because the tints + shades below need them.)

**Secondaries — dye path (primary dye + primary dye):**

| Mix | Result |
|---|---|
| Red + Yellow | Orange |
| Yellow + Blue | Green |
| Blue + Red | Purple |
| Red + Yellow + Blue | Brown |

**Secondaries — flower path (primary flower + primary flower):**

| Mix | Result |
|---|---|
| Field Poppy + Buttercup | Orange Dye |
| Buttercup + Cornflower | Green Dye |
| Cornflower + Field Poppy | Purple Dye |
| Field Poppy + Buttercup + Cornflower | Brown Dye |

Black/White (and therefore tints/shades) have **no flower path** — they come
from Ink Sac / Bone Meal, so the dye path is the only route to those.

**Shades (colour + Black) and tints (colour + White):**

| Mix | Result |
|---|---|
| White + Black | Grey |
| Grey + White | Light Grey |
| Red + White | Pink |
| Green + White | Lime |
| Blue + White | Light Blue |
| Purple + Pink (or Red+Blue+White) | Magenta |
| Green + Blue (or Blue+Green) | Cyan |
| any colour + Black | darker shade |

This reaches the full ~16-colour set from **5 base dyes** (R/Y/B + W/B) plus
mixing — no flower-per-colour sprawl.

### 4. First consumer — dyed paper (NOT the blueprint)

The conversation that started this (2026-05-27) reached an important split:
**dyeing paper and making a blueprint are different things, and must not be
confused.**

- **Dyed paper** = `Papyrus Sheet + dye` → **coloured paper**, a decorative
  material → **wallpaper, bunting, paper lanterns, kites** (its own follow-on
  spec). This is the dyes' real first home — a far richer consumer than a
  single blue plan.
- **The blueprint is NOT dyed.** It's blue because it's a *sun-printed copy*
  (a cyanotype), which is a wholly separate process — paper + iron + salt,
  then sunlight. See **[Blueprint / Cyanotype](2026-05-27-blueprint-cyanotype.md)**.
  Keeping them separate is deliberate: a blueprint must never read as "just
  blue paper".

So Phase 2's dye consumers point at **coloured paper + décor**, not at Plans.

## Build phasing (incremental, each shippable)

- **Phase 1 — Primaries + the blue blueprint.** 3 flower blocks + worldgen
  scatter + flower items; 3 dyes (flower→dye); Blue-Dye→Blueprint-Plan
  consumer + blue Plan texture. *Delivers the original goal: an earned blue
  blueprint.*
- **Phase 2 — Full paintbox.** Black + White dyes (Ink Sac / Bone Meal) +
  all mixing recipes — **both** the dye-mix and flower-mix paths to the
  secondaries, plus the tints/shades. 16 colours.
- **Phase 3 — More consumers.** Coloured wool, banners, beds, etc. (own
  follow-on specs; out of scope here).

## Data model (build notes)

- **Flowers:** new `BlockId`s (Cornflower, Field Poppy, Buttercup) + the
  matching item drops; reuse the decorative-plant placement pattern. Block
  textures + item textures appended at the end of the registries (append-only
  to preserve bincode/texture-layer order — same discipline as every prior
  block wave).
- **Dyes:** `MaterialId` variant per colour (Blue/Red/Yellow/White/Black +
  the mixed colours). Trade/complexity values per the farming-economy ladder.
- **Recipes:** shapeless grid recipes in `crafting.rs` (`match_recipe`):
  flower→dye (single primary), dye+dye→mixed, **and flower+flower→mixed**
  (the second path to each secondary — same output as the dye-mix). Add
  `is_dye_slot` / `is_primary_flower_slot` predicates if they keep the
  matcher clean.
- **Plan colour:** extend the Plan item with a colour/grade field; texture
  picker keys off it. Coordinate with `plan.rs` / `plan_ui.rs`.

## Verification & boundary
