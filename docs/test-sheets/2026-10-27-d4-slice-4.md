# D4 slice 4 — death, rescue and kill credit

Build: v0.2.27 (protocol 95, save 59), D4 slice 4, based on main `ee023ea2`. Standalone remains the default; `--solo-hosted`
uses the local authority. Run once in each mode, then repeat the multiplayer
steps on an operator-run dedicated server. The two-machine session can wait.

- [ ] Kill a wild mob. It disappears once, leaves one set of normal loot and
  advances the relevant challenge/bounty once. Let several ticks pass; there
  should be no repeat credit or duplicate drop.
- [ ] Kill a wild Nostrich near a tamed one: the wild kill still invokes the
  Vow. An ordinary death of the tamed bird alone does not.
- [ ] Place a Pet Bed near a tamed pet, then let a hostile kill it. It appears
  alive at the bed with full health; no loot, death credit or missing cargo.
- [ ] Deliberately sneak-cull your own pet near that bed: the cull sticks.
- [ ] Kill a packed donkey or mule. Its equipped Chest and every cargo stack
  spill once. Try two packed steeds together; each retains its own contents.
- [ ] In multiplayer, let the joiner land the final hit while the host stands
  closer. Only the joiner gets credit. If that joiner leaves before the mob
  dies, neither the host nor a replacement joiner inherits the kill/Vow.
- [ ] With a bow, check that death/drop timing feels unchanged: local and
  solo-hosted play settle a projectile kill on the following tick; dedicated
  server play uses its usual server timing.
- [ ] Save and reload an owned pet after rescue. Its owner and cargo remain
  correct. If saving says deaths are still being resolved, resume play briefly
  before retrying; do not discard the world to work around it.

- [ ] Start hosting while several mobs die together. Admission can briefly
  wait for those deaths, then recover while existing play and controls keep
  working. A disk/save fault still needs a fresh hosting attempt after repair.

Record the mode, host/joiner, pet species and any mismatch.
