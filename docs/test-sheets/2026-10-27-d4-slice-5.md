# D4 slice 5 — machines and projectile ownership

Build v0.2.27, protocol95/save59; base main43164e14. Standalone remains the
default. Repeat local steps in standalone and `--solo-hosted`, then use a
self-hosted dedicated server with a native joiner. Owner playtests are pending;
automated evidence is recorded separately in the lane report.

- [ ] Fuel a campfire and cook food. Fuel/cooking speed feels unchanged; smoke
  appears and clears, the lit block and surrounding light settle for everyone.
- [ ] Put green logs on an uncovered drying rack. They progress; a block above
  stalls them; removing the block resumes them. Save/restart retains progress.
- [ ] Smelt ore in a furnace while another player has its screen open. Input,
  output, fuel and lit state agree and never advance twice while hosting.
- [ ] Use a powered dispenser, piston and hopper. Each eject/push/transfer
  happens once. Joiners see the same blocks and items.
- [ ] Build a manual Blueprint, save part-way through, restart and finish.
  Materials and placement continue once; one final plaque appears.
- [ ] Complete an NPC Builder commission in a local world. It finishes and the
  Builder returns; generic construction must not strand the commission.
- [ ] Place/remove a workstation near an existing villager. Its profession
  claims/releases as before. This is not a claim of dedicated quest support.
- [ ] In a power challenge, stamp or push a lit device. That alone must not
  finish the objective; powering a real unlit device still does.
- [ ] Trigger a permitted keg near a player/chest. Damage/armour/parrot
  effects and chest closure occur once, with one blast and no duplicate loot.
- [ ] Shoot a mob with a bow. Local and solo-hosted death/drop timing remains
  the following early tick; dedicated play retains its server timing.

Record mode, host/joiner and a reproducible sequence for any mismatch. NPC
commissions/quests, dedicated village population and chest auto-collection
retain their documented capability limits; no defaults have been flipped.
