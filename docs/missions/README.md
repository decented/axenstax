# Test missions

Short, hands-on missions for playtesting each new build of Axe'n'Stax.

| File | What it is |
|---|---|
| [`latest.md`](latest.md) | The full guide for the current build: every mission with what to type, exact numbers, what success looks like, and what to check if it does not work. Plus how the systems work, the commands, and a feedback template. |
| [`cohost-instructions.md`](cohost-instructions.md) | Instructions to give a chat assistant so it can co-host a playtest video and answer questions from the guide. |

The printed test sheet is a one-page summary of `latest.md`. Each new build replaces `latest.md`; older guides stay in the git history.

Missions are grouped so each sheet needs one setting:
- **Sheet 1:** on your own, on open grass.
- **Sheet 2:** at a village.
- **Sheet 3:** with a friend.
