# Axe'n'Stax — Player Guide

Welcome. This is the player's guide to Axe'n'Stax. It covers how to play, what every block and tool does, how villages and quests work, and how the sats economy fits in.

It's written for players first. Everything here matches what the alpha build actually does today; when the game changes, this guide changes with it.

## Where to start

**Brand-new to the game? Go to the [Tutorials](https://learn.axenstax.com/docs/journey/learn-journey/index.md) first.**
They walk you through playing — mining, crafting, cooking, surviving your first
night, farming — one step at a time. This guide is the **reference**: come here to
*look things up* (what a block is, what a mob drops, how a recipe is shaped). The
tutorials are for *learning to play*.

After the tutorials, dip into whichever section below is on your mind — each page
stands alone. Or read the one-page **[Getting Started](getting-started.md)** for a
quick first-five-minutes summary.
