# The Site Board

A Site Board is a shared job list for a crew. Pin it up by a build, pick the jobs you are all working on, and tick them off as they get done.

> **Not the Challenge Board.** The **Challenge Board** you open with **J** lists **Trials**. See **[Minigames](minigames.md)**. The Site Board is a block you craft and place.

## Make a Site Board

Craft it at a **Crafting Table**. A column of **three planks** in the middle, with a column of **sticks** on each side. That is three planks and six sticks:

| | | |
|---|---|---|
| **Stick** | **Plank** | **Stick** |
| **Stick** | **Plank** | **Stick** |
| **Stick** | **Plank** | **Stick** |

Any planks work, from any wood. In Creative mode the board is in the creative inventory. Mine it with an axe.

## Use it

**Right-click** a Site Board to open its list. The list shows up to **eight jobs**.

- **Add a job.** Open **Add a job** and pick one from the list.
- **Tick it off.** Each job has a tick for when it is done.
- **Remove it.** Take a job off the board with **Remove**.

**Anyone can add, tick or remove a job.** There is no owner. Everyone in the world sees the same board, and the board is saved with the world.

If the board is empty it says "Nothing on the board yet." If it is full it says "The board is full. Take a job off to add another."

## The twelve jobs

You choose from a fixed list. There is no typing, so it is not a chat.

| | | |
|---|---|---|
| Plant trees | Build walls | Build a roof |
| Dig a well | Light the way | Make a garden |
| Bring food | Gather wood | Clear the ground |
| Build a bridge | Fence the animals | Decorate |

## What it does

- **It tells a crew what is next.** Everyone can see the list.
- **Ticking a job done gives the place a small cheer.** Confetti pops over the board and the place gets a small lift in **[bloom](bloom.md)**. That happens once per board per game day, so ticking and unticking does not pump it up.

## Limits

- Eight jobs on a board at a time.
- No free text, on purpose.
- The cheer is once per board per game day. Ticking more jobs the same day still ticks them, with no extra cheer.
- The cheer is forgotten if you save and reload, so the board can cheer again after a reload.
