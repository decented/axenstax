What this is checking

The engine renders through WebGPU, the new browser graphics API. WebGPU is on by default in Chrome 121+ and Edge 121+. Brave ships it but keeps it behind a flag. Firefox and Safari are still stabilising — we'll add them when they're broadly ready.

This page only asks your browser whether a GPU adapter is available. It doesn't load the engine, doesn't sign you in, and doesn't keep any data.
