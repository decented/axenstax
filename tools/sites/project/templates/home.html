Full custom build

No Luanti, no Veloren — own the entire stack. Rust compiles to WASM for the browser and native for desktop. One renderer (wgpu) across WebGPU, Vulkan, Metal, DX12.

Self-hostable

Run a single binary on your laptop, or a Docker container today. You run it yourself; there is no AxeNStax-operated hosting. Same engine, same world format.

Your server, your rules

Operators set their own economy and moderation — no licence dictating what you build or how you monetise. Proof-of-play surfaces a real SHA-256 hash on every strike, driving rare drops today; a parent-controlled Lightning payout path for servers that opt in is designed, not yet switched on. All optional — the engine runs perfectly without any of it.

Specs as source of truth

Eight deep specs — engine, world format, rendering, networking, gameplay, Bitcoin, platform, security — plus ADRs and a public roadmap. The engine is rebuilt from these.

Build & host
