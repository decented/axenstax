# Axe'n'Stax brand assets

The Copperline / Path to the Peaks identity: logos, marks, app tiles, favicon
and UI icons, all plain vector SVG. Read `BRAND-GUIDELINES.md` before using
them; `PREVIEW.png` shows the whole set.

This directory is the canonical copy. The websites keep their own copies under
`tools/sites/<site>/static/`; run `brand/sync-sites.sh` after changing anything
here.
