# Credits

Axe'n'Stax is a full custom build — engine, client, and server code are all
original to this project. This file tracks non-code creative assets that
aren't ours to begin with.

## Art gallery

The art Gallery is an **optional external world pack** (a `.axeworld` file you
load with the normal world import), not part of this repository. Its artwork
belongs to the individual artists, is used with their permission, and is not
covered by this repository's MIT licence; the pack carries its own credits.

## Third-party software

AxeNStax is built on a large number of open-source Rust crates and a
handful of JavaScript/Python dependencies. A generated, per-release
third-party notices file ships alongside each native package (see
`tools/packaging/about.toml`) rather than being maintained by hand here.

See [`docs/brand/brand-identity.md`](docs/brand/brand-identity.md) for the
